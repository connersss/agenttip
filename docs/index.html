AgentTip

Tip any Agent ID holder by their .ai name, on BNB Chain.

Tips are irreversible and go directly to the Agent ID owner. Always resolve the name first and check the recipient address before you tip. AgentTip charges no fee and holds no funds: the full amount is forwarded in the same transaction.
Not connected

Works with MetaMask or Binance Wallet (injected provider, EIP-1193). No QR-code login, no account on any server. Switch your wallet to BNB Chain (chain ID 56).
